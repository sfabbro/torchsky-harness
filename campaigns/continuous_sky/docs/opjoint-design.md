# opjoint: multi-field joint global-local inversion (design note, 9 Nov 2026)

Script: `scripts/opjoint.py` (new). `opfield.py` is NOT edited (sha256 recorded in `tests/opfield.sha256`, checked by the tests), so single-field opfield is unchanged bit for bit.
It imports `OpField`, `Pool`, `PeakSampler`, `fit_nuisance`, `evaluate`, `xfit_step`, `write_outputs` from opfield and the A13 registration and pooling helpers from tilefit.

**Problem.** Data of several fields (LMC tiles from the plan, SMACS JWST + WFC3/IR). ONE field operator theta (geometry mu, PSF Psi, transmission a, detector terms, noise head); a catalogue-free sky s_k per tile; a code z_i per exposure.
This is a global-local inverse problem: theta is global, (s_k, z_i, nuisances) are local. It is not "learn on A, freeze, transfer"; transfer is only the validation (leave-field-out, T5).

**Global (one copy on the GPU, in one Adam):** hypernetwork trunk, instrument and detector embeddings, heads for mu / Lambda / a, shape MLP, bank, base rows (per `--base-per`), two-scale wing tables and fractions, g / noise / outlier nets, per-detector pattern `pd`, mu-skip.
**Local:** tile sky (12 RBF coefficients per pixel) and its xfit views; per-exposure z_i, quadratic background `pe`, NIRCam stripes, hierarchical epoch/visit codes (`--z-hier`); the per-tile constant background b0. An exposure seen in several tiles has ONE z_i / pe / stripes row (global exposure id), but a different x0, pixel set and b0 per tile.
Every exposure has one row in the global exposure table (meta = J, roll, band, detector, epoch ...); the OpField is built once on that table, `model.sky` is swapped per tile.

**Loop (one cycle):** pick tile k with probability p_k; (a) K inner steps on s_k only (all other parameters `requires_grad=False`, own batch, own optimiser state), (b) one joint step: the data loss of a fresh batch plus priors and gauges updates theta, the active nuisances and s_k (two Adam objects: operator, tile sky). Cross-fitting (`--xfit-reg`) and coarse-to-fine act per tile through the same `xfit_step` / `c2f_sigma` of opfield; progress p = max(cycle/steps, elapsed/budget) is global.
A visit = `--visit-cycles` cycles on one tile (amortises the swap). p_k = tile pixels^gamma, per-field share floored at `--field-floor` (default 0.2), overrides `--tile-weights`; per-instrument loss weights `--inst-weights` (default 1).
**Memory:** on the GPU only theta + its Adam state + all per-exposure nuisance (small), the ACTIVE tile's sky + Adam state (+ views), the ACTIVE tile's pixel pool (a random 1/`chunks` of it if it exceeds `--gpu-pool-gb`) and its PeakSampler (one per tile, rebuilt and refreshed at each visit). Inactive skies and optimiser states sit on the CPU; pools in RAM (compact, 33 B/px) or on disk.
**Registration:** `--shifts-from` = tilefit A13 (`apply_external_shifts`, header CRVAL shifted too); SMACS keeps opfield's own `--coarse-shift` (HST) / `--coarse-shift-jwst`.

**Tests/scores.** T1 per tile, per field and per instrument (opfield `evaluate`, pipeline sigma, S/N>5 mask, dither-cluster bootstrap, `--score-coadds`); joint SMACS score (same split as the references); T5 (held-out tiles: local-only refit with private exposure ids + control that refits the operator on the tile alone); `--leave-out-field NAME` (train without, then refit sky/z/nuisance/hier codes only and score T1; global parameters verified unchanged); kernel diagnostics + `--dump-heldout-pixels` via opfield's writers.
CPU tests: 2 fields / 2 instruments (joint beats separate on a thin field), local-only refit on a left-out field, inner steps leave the global parameters bit-identical, single-tile K=0 opjoint reproduces `opfield.train`, opfield sha256 unchanged.

**Approximations** (J1...; full list in the docstring and metrics.json): J1 one Jacobian/roll/scale per exposure from the tile where it has most pixels; J2 b0 per tile; J3 gauges evaluated on a random subset of training exposures (all if <= `--gauge-exps`); J4 priors/stripes penalty restricted to the active tile's exposures; J5 tile sampling != pixel-proportional because of the floor; J6 inner sky solve is K Adam steps (not exact VarPro); J7 pool chunking; J8 Adam moments of rows absent from a tile decay; J9 no `--restart-cycles`, no factorised operator; J10 T5 / control budgets.

## Update (9 Nov, later): fields as data, leave-field-out in two stages, tests, runner

- **`--fields-config FILE`** (`scripts/fields_p1j.json`): `plan` fields (tiles of a plan_tiles.py plan, A13 `shifts_from`, held-out tile ids, T1 dithers per tile) and `frames` fields (one tile from image directories, as SMACS); each has an `"args"` dictionary overriding any opfield flag for that field only. New fields / instruments are entries of this file. The legacy `--fields LMC,SMACS --plan` flags build the same structure.
- **`--holdout-field NAME`** (alias `--leave-out-field`): (i) local-only refit (sky, codes, nuisances; global parameters frozen and verified bit-identical), (ii) with `--lo-ft-cycles N` a fine-tune of everything from that state at `--lo-ft-lr-mult` x learning rates. Both T1 scores are reported (`T1`, `T1_finetune`).
- **Checkpoints per fit** (`ckpt_<tag>.pt`): the T5 control and the fine-tune never overwrite the main resume point (a bug in the first version).
- **Equivalence with opfield**: one tile, `--inner-sky 0`, `--visit-cycles >= steps`: bit-identical to `opfield.train` on the CPU (tests/test_opjoint.py, 25 steps, max difference 0.0). Defaults (K=2, visit 25) and GPUs are not.
- **Tests** (tests/test_opjoint.py, CPU, 15 min): two fields / three tiles / two instruments of different PSF width and pixel scale; joint vs single-field fits; leave-field-out vs joint; T5 vs control; swap-gradient equality; pool chunks; shared exposure ids; fields config; equivalence with opfield.train. A smoke run of the whole script on the SMACS crop test data (a frames field plus a 3-tile plan field with A13 shifts, T5 + control, coadd scores, pixel dumps, leave-field-out + fine-tune) ran to completion.
- **Runner**: `scripts/run_opjoint.sh` (run_tilefit.sh environment; SCRIPT defaults to opjoint.py; sha256 of opfield / tilefit / v36 in the provenance; the fields config is copied into the provenance).
